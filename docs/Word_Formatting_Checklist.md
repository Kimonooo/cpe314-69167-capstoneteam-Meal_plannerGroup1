# Word formatting checklist (we lost points here in Week 8!)
Tick each box when you have checked the WHOLE document, not just your new part.

- [ ] Body font is **Calibri 11** everywhere (select all with Ctrl+A and look at the font box).
- [ ] Margins are 1 inch on all sides (Layout tab, Margins).
- [ ] Every section title uses **Heading 1** and sub-titles use **Heading 2/3** (never just bold text).
- [ ] Body text is left-aligned or justified (never centered).
- [ ] Line spacing is 1.15 to 1.5 for paragraphs; inside tables it is single.
- [ ] Every table has a caption **ABOVE** it: "Table N: short description".
- [ ] Every picture has a caption **BELOW** it: "Figure N: short description".
- [ ] Table and Figure numbers go 1, 2, 3... in order, with no gaps and no repeats.
- [ ] Code is in **Consolas 9 or 10** and each piece is under about 20 lines.
- [ ] No gray template help text is left over in any section.
- [ ] No `[YOUR TURN]` or `[FILL]` anywhere (use Ctrl+F to search).
- [ ] Revision History row **0.3** is filled in.
- [ ] Table of Contents is updated (F9) and shows Sections 1 to 7.
- [ ] Page numbers show in the footer.
- [ ] Title page has the project title, group name and all 6 member names.
